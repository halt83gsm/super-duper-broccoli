📖 Hướng dẫn import
1Xuất file từ hệ thống Green SM: car_attendance_tracking + statistic_attendance_tracking mỗi ngày. Xuất file driver và vehicle mỗi tuần hoặc khi có thay đổi.
1Import 📋 File tổng hợp chấm công & vận doanh — dữ liệu cốt lõi (statistic_attendance_tracking_*.xlsx). Có thể upload nhiều file cùng lúc.
2Import 👤 File thông tin tài xế — cập nhật tổ, trạng thái, loại TX (driver_*.xlsx). Tự động cập nhật Resign/Resigning.
3Import 🚗 File thông tin xe — trạng thái xe, đăng kiểm, phù hiệu (vehicle_*.xlsx).
4Nhấn 🔄 Áp dụng dữ liệu để load toàn bộ dashboard. Có thể import lại bất cứ lúc nào để cập nhật mới nhất.
5Nhấn "Áp dụng dữ liệu" để cập nhật toàn bộ dashboard. Dữ liệu được lưu trong phiên làm việc (refresh trang sẽ mất, cần import lại).
⚠️ Định dạng hỗ trợ: .xlsx, .xls, .csv — File phải xuất thẳng từ hệ thống Green SM, không chỉnh sửa cấu trúc cột. Tên cột cần có: Mã tài xế, Tên tài xế, Ngày phân công, Doanh số, Số cuốc xe hoàn thành, Tổng thời gian online, Công chính...
